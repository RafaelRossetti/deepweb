# Thor Cyber-Intrusion Simulator

Este é um simulador de hacking realista baseado na interface diegética do App Thor.

## 🚀 Como Executar
1. Instale um servidor local (ex: extensão Live Server do VS Code).
2. Ou execute `npx http-server .` na raiz da pasta.
3. Acesse `http://localhost:8080`.

## 🎮 Funcionalidades
- **Terminal Realista**: Sistema de logs com efeito de digitação e histórico.
- **Mapa de Rede**: Visualização dinâmica de alvos detectados.
- **Sistema de Detecção**: O "Trace" aumenta conforme você realiza ações agressivas.
- **Persistência**: Seu progresso é salvo automaticamente via `localStorage`.

## 🛠️ Tecnologias
- **HTML5/CSS3**: Estilização personalizada com efeitos CRT.
- **Vanilla JavaScript**: Lógica do jogo pura, sem frameworks pesados.
- **Diegetic UI**: Toda a interface faz parte do "computador" do jogador.
